# Catalogue Prisme UI

Application de développement permettant d'examiner les composants partagés avec des données fictives.

## Lancer

```powershell
flutter pub get
flutter run -d windows
```

`flutter run -d chrome` ouvre une revue dans le navigateur local. Pour Android, utiliser un appareil connecté et une toolchain SDK configurée.

La barre d'outils permet de choisir le thème, la densité et la langue. `Ctrl+K` recherche une rubrique. Le menu Plus permet d'accéder à toutes les rubriques sur mobile. Les confirmations sont des démonstrations locales ; aucune connexion à une infrastructure n'est configurée.

Voir le [guide de la bibliothèque](../README.md) pour les API et les règles d'intégration. Les runners, signatures et identifiants de ce catalogue ne sont pas ceux d'une application à distribuer.
